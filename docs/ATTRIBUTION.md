# 来源与贡献边界

本项目基于收到的「智扫通机器人智能客服」源码进行复现和工程化修复。

原 README 指向：[bamboo-moon/zhisaotong-Agent](https://github.com/bamboo-moon/zhisaotong-Agent)。
原 README 声明“本项目仅供学习与参考使用”，并感谢黑马程序员开源免费项目、阿里云和高德地图等开放平台。
本次保留这些来源与致谢，不将原始 Agent/RAG 架构、提示词构思和知识库数据宣称为全新原创成果。

原目录及上游仓库未包含可识别的独立 LICENSE 文件。本次没有擅自添加 MIT 等许可证。
原始 1 个 PDF 与 5 个 TXT 知识文档保留在本机，由 `.gitignore` 排除，不进入公开候选提交；
仓库只附带本次为展示编写的品牌无关 `data/demo_knowledge.txt`。上游代码的再分发授权仍需发布者自行核实。

本次工程化贡献：运行环境排查、会话历史传递、工具结果过滤、API 环境变量和异常处理、CSV 解析、
真实系统月份与演示身份、幂等索引、自动化测试、可复现文档及真实界面验证。
